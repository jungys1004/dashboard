# 국방예산 웹 대시보드

`index.html`을 브라우저에서 열면 바로 실행됩니다. 설치나 인터넷 연결이 필요 없습니다.

- 부문 / 회계구분 필터 및 프로그램 검색
- 4개 지표 카드와 8개 인터랙티브 SVG 그래프
- 상세 표 정렬 및 필터 결과 CSV 다운로드
- 모바일 화면 대응

원본: 상위 폴더의 `붙임1_프로그램별_재원.xlsx`. 금액 단위는 억원이며, 2027년은 정부안입니다. 원본의 32개 데이터 행을 사용합니다.

엑셀을 수정한 뒤에는 Python으로 `update_data.py`를 실행하고 페이지를 새로고침하세요. Python 표준 라이브러리만 사용합니다.

순재원에는 음수 내부거래·보전지출을 포함합니다. 원형·면적 그래프는 양수 재원만 사용하며, 순재원 비중과 구별됩니다. 증감률은 `(2027년 - 2026년) / 2026년`으로 계산합니다. 원문 반올림으로 합산액과 원문 총액이 다를 수 있습니다.
